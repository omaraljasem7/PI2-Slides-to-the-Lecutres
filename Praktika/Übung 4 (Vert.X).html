In der Übung der letzten Woche haben Sie das Adder-Beispiel mit Express, also den Server mit TypeScript umgesetzt. Heute geht es darum, den Server-Teil in Java mit Vert.X zu implementieren. 
Bitte nutzen Sie dazu den Generator auf https://start.vertx.io/ und verwenden Sie die Group Id “de.thm.mni.pi2” und die Artefact-ID "adder"; wählen Sie bei "Show dependencies panel" die Option Vertx Web aus und generieren Sie das Projekt.

1) 

a) Entpacken Sie das Projekt (zip-file) und starten öffnen Sie es als Projekt mit IntelliJ oder öffnen Sie den Ordner mit VisualStudio Code.

b) Führen Sie das MainVerticle aus (siehe Anleitung auf Folie "Eclipse Vert.X"). Rufen Sie die Route, die das MainVerticle anbietet, im Browser auf (welche URL müssen Sie verwenden?).

c) Legen Sie ein "AdderVerticle" an, indem Sie die gleiche Route /add  implementieren wie in dem Express-Server, Ermöglichen Sie auch, dass man adder.html über Ihren Server aufrufen kann.
   Testen Sie mit der adder.html Seite der letzten Woche.

2) 

a) Fügen Sie eine Route /count hinzu, die die Anzahl der Aufrufe der Route /add zurückgibt.

b) Erstellen Sie eine Route, die z.B. bei Aufruf GET /monat/11 die Antwort "November" zurückliefert.

c) Recherchieren Sie, wie man CORS in VERT.x erlaubt.
