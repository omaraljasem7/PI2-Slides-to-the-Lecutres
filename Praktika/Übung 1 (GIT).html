In diesem Aufgabenzettel geht es um die praktische Nutzung von GIT.

Aufgabe 1

Vorbereitung:

- Generieren Sie einen Schlüssel und laden Sie diesen nach git.thm.de hoch (siehe Vorlesung).
  Kopieren Sie Ihren öffentlichen Schlüssel (Endung: .pub), nicht den privaten!

- Setzen Sie die globalen Attribute (siehe Vorlesung).

- Installieren Sie die "git bash".

- Erstellen Sie auf git.thm.de ein neues Projekt "Testprojekt".

- Clonen Sie dieses auf Ihrem Rechner und wechseln Sie in der git Bash in dieses Verzeichnis.

Aufgabe 2

Führen Sie in der git bash folgende Aktionen durch:

a) Legen sie eine neue Datei a.txt an: touch a.txt
    Verifizieren Sie mit   cat a.txt  , dass die Datei leer ist.

b) Fügen Sie diese Datei Ihrem Index hinzu und setzen Sie den HEAD auf diesen neuen Stand.

c) Lassen Sie sich den log anzeigen.

d) Fügen Sie eine Zeile in die Datei ein und speichern diese neue Version.

e) Zeigen Sie den Unterschied zwischen der neuen und der vorigen Version an.

f) Ermitteln Sie die Nummer des vorigen Commits und setzen Sie den HEAD auf diesen zurück. Verifizieren Sie, dass die Datei leer ist.


Aufgabe 3 (Git Issues)

a) Öffnen Sie ein bestehendes Git-Projekt oder legen Sie ein neues an. Legen Sie eine Markdown-Datei mit beliebigem Inhalt darin an und comitten Sie diese.

b) Erlauben Sie unter Settings -> General -> Visibility  das Anlegen von Issues.
    Jetzt sollten Sie links einen neuen Menüpunkt "Plan" sehen.

c) Legen Sie ein Issue "Markdown anpassen" an und weisen Sie es sich selbst zu.
    Wo sehen Sie jetzt das neue Issue?
    "Bearbeiten" Sie das Issue und schließen Sie es.
   Wie können Sie sich das nun geschlossene Issue noch ansehen?

d) Legen Sie ein weiteres Issue an, weisen es sich selbst zu. Vor dem Schließen sollen Sie einen neuen Branch anlegen (wo geht das beim Bearbeiten des Issues?), die Datei ändern und einen Merge Request erstellen.
Approven Sie den Merge Request und führen Sie ihn durch. Welchen Status hat das Issue danach?
