Aufgabe 1

Heute bauen wir das WebService-Beispiel aus der Vorlesung nach. Bitte wenden Sie die Schritte der Reihe nach an und melden Sie sich, sollten Fehler auftreten.

  1. Starten Sie WebStorms
  2. Legen Sie ein neues Projekt des Typs "Express" an.
    Wählen Sie unter 'Location' einen geeigneten Ort und Namen für Ihr Projekt.
    Wählen Sie 'View Engine'=none und 'Stylesheet Engine'=Plain CSS.
    'Node Interpreter' und 'express-generator' sollten gefüllt sein.
    Nach 'Create' sollten Sie ein Projekt haben, welches schon einen Ordner 'public' und andere hat.
  3. Erzeugen Sie eine 'tsconfig.json' Datei - wissen Sie noch, wie das geht?
    Verifizieren Sie bitte, dass in der Datei "esModuleInterop" auf "true" gesetzt ist.
  4. Setzen Sie für TypeScript "Recompile on Changes" - wissen Sie noch wo?
  5. Installieren Sie die Node-Typen für TypeScript. Dazu öffnen Sie ein Terminal (z.B. in WebStorm ganz unten) und geben ein:
    npm install -D @types/node
    npm install -D @types/express
     Damit werden dem TypeScript-Compiler die Typen aller in Node und Express vordefinierten Funktionen
    bekannt gemacht. Ohne diese lässt sich die folgende TypeScript-Datei nicht kompilieren.
  6. Installieren Sie Express:
    npm install express
  7. Kopieren Sie drei Dateien adder.html, adderFetch.ts und adder.ts (siehe Moodle-Kurs) und legen Sie sie im Projekt wie folgt ab:
    adder.html -> 'public';
    adderFetch.ts -> 'public/javascripts'
    adder.ts -> in den Hauptordner.
  8. Starten Sie 'adder.js'
    Sie sollten eine Meldung 'Server running on port 3000' sehen.
  9. Öffnen Sie im Browser die folgende URL:
    http://localhost:3000/adder.html
